# Тағам термометрі · Термометр для блюд (ESP32 + DS18B20)

**Қысқаша (қаз.):** асхана қызметкері қосымшада тағамның «Термометрмен өлшеу» батырмасын басады, датчикті тағамға батырып, құрылғыдағы батырманы басады — температура сол тағамның журналына өзі жазылады, нормамен (сорпа ≥75 °C, екінші тағам ≥65 °C) салыстырылады және порция фотосымен бірге СЭС-ке көрінеді. Құрылғы болмаса, температура қолмен енгізіледі.

Ниже — как собрать устройство и подключить его к задеплоенному сайту.

## Что нужно

| Деталь | Примечание |
|---|---|
| Плата **ESP32** (ESP32 DevKit / ESP32-WROOM) | нужен Wi‑Fi; кнопка BOOT и светодиод уже есть на плате |
| Датчик **DS18B20 в стальной гильзе на проводе** (водонепроницаемый) | диапазон −55…+125 °C — подходит для супа и кипятка |
| Резистор **4,7 кОм** | подтяжка линии DATA к 3,3 В |
| Макетная плата и провода, кабель USB | |

> DHT11/DHT22 не подходят: они меряют воздух и не рассчитаны на погружение в горячую еду.

## Схема

```
DS18B20 красный  (VCC)  → 3V3
DS18B20 чёрный   (GND)  → GND
DS18B20 жёлтый   (DATA) → GPIO4
резистор 4,7 кОм        → между GPIO4 и 3V3
```

## Прошивка

1. Arduino IDE → Board Manager → пакет **esp32** (Espressif) → плата «ESP32 Dev Module».
2. Library Manager → **OneWire** (Paul Stoffregen) и **DallasTemperature** (Miles Burton).
3. Откройте `esp32-thermometer/esp32-thermometer.ino` и заполните:
   - `WIFI_SSID`, `WIFI_PASS` — сеть (на защите удобно раздать Wi‑Fi с телефона);
   - `API_URL` — `https://<ваш-сайт>/api/device/readings`;
   - `DEVICE_KEY` — ключ устройства: значение `DEMO_DEVICE_KEY` из `.env` (seed регистрирует его как термометр столовой школы №AD) или новый ключ со страницы `/kitchen` → «Құрылғылар» → «Кілт алу».
4. Загрузите прошивку, откройте Serial Monitor (115200): там видно температуру и ответы сервера.

## Как показать на защите

1. Войдите на сайт как `ad_kitchen` (столовая школы №AD).
2. У блюда нажмите **«Термометрмен өлшеу»** — светодиод на плате начнёт мигать.
3. Опустите датчик в горячую воду/суп и нажмите **BOOT**.
4. Через секунду в приложении появится температура с отметкой «құрылғыдан», а в СЭС (`ses1`) — в журнале столовой.
   Если суп остыл ниже 75 °C, приложение сразу пишет «Беруге болмайды: қайта қыздырыңыз».

## API (для любого устройства)

```
POST /api/device/readings
Authorization: Bearer <ключ устройства>
Content-Type: application/json

{"value": 78.4}
```

Ответ: `{"ok":true,"status":"OK"|"VIOLATION"|"SAVED","dish":"Картоп сорпасы","norm":{"min":75}}`.
`GET` с тем же ключом возвращает, ждёт ли приложение замера (`"armed": {"dish": …}`).
Ключ хранится на сервере только в виде sha256-хэша; отключить устройство можно на странице `/kitchen`.

## Проверка без железа

```bash
node --env-file=.env scripts/device-sim.mjs --state
node --env-file=.env scripts/device-sim.mjs 78.4
```

Для задеплоенного сайта добавьте `BASE_URL=https://<ваш-сайт>`.
