# Презентацияға арналған слайдтар

`risk-score.html` — тәуекел балы 0–100 қалай жиналады (сандар `src/lib/risk/config.ts`-тен).
Тілі URL параметрімен: `?lang=kk`, `?lang=ru`, `?lang=en`. Браузерде ашып, мәтінін түзетуге болады.

PNG (3840×2160) қайта жасау — Windows-тағы Edge арқылы:

```bash
"/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --headless=new --hide-scrollbars --window-size=1920,1080 --force-device-scale-factor=2 --virtual-time-budget=8000 --screenshot="C:/serzhan/qauipsiz-as/docs/pitch/risk-score-kk.png" "file:///C:/serzhan/qauipsiz-as/docs/pitch/risk-score.html?lang=kk"
```
